# Portrait sources

The three exhibit murals are deterministic paper-and-ink transformations of the locally stored source photographs. Install the pinned preprocessing dependency with `python -m pip install -r scripts/requirements-portraits.txt`, then run `python scripts/process-portraits.py` to regenerate the PNG assets in `public/portraits/`.

The source files are kept in `assets/portrait-sources/`; the application serves only the transformed local PNG files and makes no runtime requests to Wikimedia Commons.

## James Lane's framed portrait

`public/portraits/james-lane-ink.png` is a monochrome print edited from a photograph supplied by James for this exhibit, using built-in image generation. The original personal photograph is not included in this repository. This asset is not regenerated by `scripts/process-portraits.py`.

Editing direction: preserve James's face, glasses, hair, expression, and three-quarter pose; crop to head and upper shoulders; remove the room background; match the existing charcoal-gray posterization, broken ink contours, and sparse halftone marks on pale paper. Produce a vertical, opaque portrait in the existing frame's 1.22:1.72 aspect ratio, without added lettering or a second frame.
