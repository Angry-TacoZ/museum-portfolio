# Portrait sources

The three exhibit murals are deterministic paper-and-ink transformations of the locally stored source photographs. Install the pinned preprocessing dependency with `python -m pip install -r scripts/requirements-portraits.txt`, then run `python scripts/process-portraits.py` to regenerate the PNG assets in `public/portraits/`.

## James Lane's framed portrait

`public/portraits/james-lane-ink.webp` is a monochrome print edited from a photograph supplied by James for this exhibit, using built-in image generation. The original personal photograph is not included in this repository. This asset is not regenerated by `scripts/process-portraits.py`.

For the 1.22 × 1.72 framed presentation, the generated 1058 × 1487 RGB PNG was resized proportionally with Pillow's Lanczos filter to 546 × 768 and encoded as WebP (quality 92, method 6). The final asset is **131,086 bytes**, down from 2,772,974 bytes (95.3% smaller). The charcoal contours, halftone marks, and warm paper remain intact; no crop or new generative edit was applied. The oversized PNG is no longer in the public assets. The optimized texture remains eagerly loaded, so it is ready before the final camera arrives and introduces no lazy-loading pop-in. Root and Pages browser verification enforce a 150,000-byte budget and verify all portrait requests in the full WebGL scene.

Editing direction: preserve James's face, glasses, hair, expression, and three-quarter pose; crop to head and upper shoulders; remove the room background; match the existing charcoal-gray posterization, broken ink contours, and sparse halftone marks on pale paper. Produce a vertical, opaque portrait in the existing frame's 1.22:1.72 aspect ratio, without added lettering or a second frame.
